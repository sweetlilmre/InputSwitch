# InputSwitch: English. This is the reference language: every other language file has the same
# keys, and anything missing from one falls back to the text here.
#
# How to translate:
# - Copy this file to <code>.txt (for example de.txt), translate the text after each "=", and
#   add the language to LANGUAGES in src/i18n.rs.
# - Keep {placeholders} as they are: the app fills them in. You can move them within the text.
# - \n is a line break. Lines starting with # are comments.
# - Keep the file UTF-8.
# - Run "cargo test" to check the file: it reports missing keys and mistyped placeholders.
